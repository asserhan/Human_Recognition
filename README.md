# Human_Recognition

# Advanced Running Detection System

An intelligent computer vision system that automatically detects and classifies human running vs walking using YOLO pose estimation and advanced biomechanical analysis.

## 🎯 Project Overview

This system solves the challenging problem of accurately distinguishing between running and walking in video footage using pose estimation and gait analysis. The algorithm adapts to different video characteristics and provides reliable classification even with partial occlusion or varying camera angles.

## 🚀 Key Features

- **Adaptive Thresholds**: Automatically scales detection parameters based on video resolution and characteristics
- **Multi-Stage Validation**: Uses 3-stage classification system for robust detection
- **Biomechanical Analysis**: Analyzes stride frequency, vertical oscillation, ground contact time, and movement velocity
- **Person-Specific Scaling**: Adapts to individual person size and distance from camera
- **Real-time Processing**: Processes video streams with live classification results
- **Debug Visualization**: Comprehensive debugging information and metrics display

pip install -r requirements.txt

## 🎮 Usage

### Basic Usage

1. **Place your video file** in the project directory
2. **Default video and output paths are already set in the script:**
   ```python
   VIDEO_PATH = "running_person.mp4"
   OUTPUT_PATH = "output_running_detection.mp4"
   ```
   You do not need to manually update these unless you want to use a different input or output file.
3. **Run the detection**:
   ```sh
   python3 yolov8n_pose.py
   ```
   - The script will process `running_person.mp4` and generate `output_running_detection.mp4` with annotated results.
### Configuration Parameters

Key parameters you can adjust in the script:

```python
# Analysis Parameters
ANALYSIS_WINDOW = 60              # Frames to analyze
MIN_DETECTION_FRAMES = 25         # Minimum frames needed for classification

# Adaptive Thresholds (automatically scaled)
BASE_WALKING_VELOCITY = 8.0       # Base walking speed in px/s
BASE_RUNNING_VELOCITY = 15.0      # Base running speed in px/s

# Frequency Thresholds
MIN_STRIDE_FREQUENCY = 1.6        # Minimum stride frequency (Hz)
RUNNING_FREQUENCY_RANGE = (1.8, 4.5)  # Running frequency range (Hz)

# Other Biomechanical Thresholds
MIN_VERTICAL_OSCILLATION = 0.08   # Minimum vertical bounce
MAX_GROUND_CONTACT = 0.60         # Maximum ground contact ratio
MIN_RHYTHM_CONSISTENCY = 0.25     # Minimum rhythm consistency

# Debug Mode
DEBUG_MODE = True                 # Show detailed metrics on video
````

# Human Recognition Project

## Project Structure

- `yolov8n_pose.py` : Main script for pose-based running/walking detection. This script uses YOLOv8 pose estimation and advanced movement analysis to classify people as running or walking in video footage.
- `running_person.mp4` : Example input video for running/walking detection. The main script processes this video by default.
- `output_running_detection.mp4` : Output video generated by the main script, showing annotated results for detected running and walking persons.
- `cctv_data.zip` : Zip archive containing additional CCTV video data for further testing or training. Unzip to access more sample videos.
- Other files and folders: Model weights, environment files, and dataset organization remain unchanged and are required for full functionality.

## How to Run

1. Install dependencies:
   ```sh
   pip install -r requirements.txt
   ```
2. Run the main detection script:
   ```sh
   python3 yolov8n_pose.py
   ```
   - This will process `running_person.mp4` and generate `output_running_detection.mp4` with annotated results.
3. For more data, unzip `cctv_data.zip` to access additional CCTV videos for testing or training.

## Notes
- The detection logic is based on velocity, vertical movement, and consistency checks, and is tuned for CCTV scenarios.
- All code and data files are organized for easy use and reproducibility.
- No changes are needed to other files; everything is ready to run as described above.
